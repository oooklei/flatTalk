# 事项：经济困难老年人护理补贴申请

## 适用对象

70周岁及以上、纳入广西最低生活保障范围的重度失能或完全失能老年人。

## 办理条件

- 年龄、低保资格、失能等级（重度或完全失能）同时符合。
- 尚未确定能力等级的，需按《老年人能力评估实施办法（试行）》开展评估。
- 与重度残疾人护理补贴就高不就低；已通过长护险基金支付基本护理服务费用的不发放。

## 所需材料

1. 《广西壮族自治区经济困难老年人护理补贴申请表》
2. 身份及低保相关信息（由乡镇/街道核验，具体以当地要求为准）
3. 能力评估相关材料（如尚未评定）
4. “一卡通”账户信息

## 办理步骤

1. 老年人或其代理人向纳入低保的乡镇人民政府（街道办事处）提出书面或线上申请并填表。
2. 乡镇（街道）在申请人所在村（社区）公示5天。
3. 公示无异议报县级民政审核批准；县级民政在收到材料后5个工作日内作出审核意见。
4. 不予批准的，县级民政书面说明理由（护理补贴不予认定告知书）。

## 窗口

户籍地或纳入低保的乡镇人民政府（街道办事处）/ 便民服务中心 → 县级民政部门。

## 时限

- 村（社区）公示：5天
- 县级审核：收到材料后5个工作日
- 待遇：原则上审批通过次月起发放

## 依据文号

桂民发〔2026〕7号

## 注意事项

- 补贴标准自治区确定为每人每月200元，地方可按规定调整。
- 本指引不替代窗口审核，地方细则优先。
