# 事项：经济困难失能老年人等群体集中照护服务补助申请

## 适用对象

纳入广西最低生活保障范围、自愿入住自治区辖区内养老机构的：
- 失能老年人（评估为中度、重度或完全失能）；
- 高龄老年人（80周岁及以上）。

## 办理条件

- 先入住、后救助：入住养老机构满30日后再申请。
- 实施长护险地区已通过基金支付基本护理服务费用的，不纳入。
- 收住机构应满足服务安全强制性标准并具备收住中度失能及以上老年人的条件。

## 所需材料

1. 《集中照护服务补助申请表》
2. 身份证及复印件
3. 养老服务协议
4. 有效缴费凭证（或机构同意缓缴证明）
5. 失能等级评估材料（需要时由县级民政组织评估）
6. 由机构代为申请的，还需委托协议

## 办理步骤

1. 选择并入住符合条件的养老机构。
2. 入住满30日后，个人或入住机构向机构所在地县级民政申请补助。
3. 县级民政审核入住及已享受补贴等情况，并在机构内或县级民政官网公示一般不少于5个工作日。
4. 符合条件的确定补助金额并发放；不符合的书面告知（不予认定告知书）。

## 窗口

养老机构所在地县级民政部门（可由家属或机构代办）。

## 时限

- 公示一般不少于5个工作日
- 补助金原则上按月社会化发放，从入住当月起算，申请通过次月起拨付至“一卡通”或授权账户

## 依据文号

桂民规〔2025〕1号（现行）。桂民规〔2024〕2号已废止。

## 注意事项

- 补助标准按当地集中照护服务标准与低保标准差额等规则核定，并扣除已享受的相关补贴。
- 不再符合条件应及时告知，按规定停发或调整。
- 本指引不替代窗口审核。
