# 事项：老年人能力评估申请

## 适用对象

广西区域内有养老服务需求的60周岁及以上老年人。尚在医疗诊治（在院）、身体状况不稳定的暂不评估。

## 办理条件

需依据评估结果申领政府补贴、补助资金，或有养老服务需求需确定能力等级。

## 所需材料

1. 《老年人能力评估申请表》及基本信息
2. 身份证明
3. 申请人近2年内病历、医疗诊断证明等（评估前提示准备）
4. 后续涉及：《老年人能力评估结果审核表》《老年人能力评估结论告知书》

## 办理步骤

1. 本人（或监护人、代理人）向居住地乡镇（街道）提出申请。
2. 乡镇（街道）核实受理后提交县（市、区）民政审核。
3. 县级民政在收到申请表后3个工作日内抽取/通知评估机构，一周内实施评估。
4. 评估机构5个工作日内完成现场评估（机构内或上门），2名评估人员同时在场。
5. 乡镇（街道）在村（社区）公示5个工作日；无异议后签署审核意见报县级民政形成结论。
6. 结论形成后5个工作日内告知申请人并签收告知书。

## 窗口

居住地乡镇人民政府（街道办事处）→ 县（市、区）民政部门指定/抽取的评估机构。

## 时限

自受理申请之日起应在28个工作日内完成。对结论有异议的，可在告知书送达之日起5个工作日内申请复评。

## 依据文号

桂民发〔2025〕34号《广西壮族自治区老年人能力评估实施办法（试行）》

## 注意事项

- 评估结果全区互认，用于补贴、照护计划、基本养老服务等。
- 评估对象原因导致3次无故推迟或取消的，可终止申请。
- 本指引不替代窗口审核。
