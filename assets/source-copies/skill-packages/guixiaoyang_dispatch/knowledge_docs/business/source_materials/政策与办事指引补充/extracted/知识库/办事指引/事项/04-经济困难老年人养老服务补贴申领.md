# 事项：经济困难老年人养老服务补贴申领

## 适用对象

户籍在广西行政区域内、70周岁及以上的低保对象和分散特困供养对象。

## 办理条件

已纳入低保或分散特困供养，且年满70周岁。符合条件的对象直接享受，信息与社会救助数据对接同步调整。

## 所需材料

一般依托社会救助信息共享办理，具体材料以当地乡镇（街道）/县级民政要求为准（通常核验身份、低保或特困资格、“一卡通”账户等）。

## 办理步骤

1. 确认是否已纳入低保或分散特困且年满70周岁。
2. 通过社会救助、社会服务“一门受理、协同办理”机制纳入发放管理。
3. 县级民政按月通过“一卡通”发放，原则上与低保金或特困供养金同步。
4. 乡镇（街道）做好增减信息搜集与状态核实。

## 窗口

乡镇人民政府（街道办事处）民政窗口 / 便民服务中心 → 县级民政、财政部门。

## 时限

原则上按月发放；名单与金额在县级政府门户网站公布。

## 依据文号

桂民规〔2024〕5号《经济困难老年人养老服务补贴实施办法（试行）》

## 注意事项

- 自治区最低标准为每人每月不低于50元，地方可提高或分档。
- 补贴不计入低保家庭收入。
- 本指引不替代窗口审核。
