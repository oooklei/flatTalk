# 事项：中度以上失能老年人养老服务消费补贴（电子消费券）

## 适用对象

经统一评估为中度及以上失能、居住地为广西、购买居家/社区/机构服务地址在广西境内的60周岁及以上老年人。

## 办理条件

- 不属于：特困供养、经济困难失能老年人集中照护补助、国家居家和社区基本养老服务提升行动项目服务对象。
- 实施周期：2026年1月至12月。

## 所需材料

通过“民政通”（小程序/APP）线上注册并提交申请；线下协助申请时按当地要求提供身份及评估信息。参与机构需符合项目机构要求并签署诚信承诺。

## 办理步骤

1. 本人或代办人通过“民政通”注册并提交领取申请（乡镇村社区或机构可协助）。
2. 按规定完成/确认能力评估（中度及以上失能）。
3. 审核通过后发放当月电子消费券；之后每月首日发放当月券。
4. 在清单范围内的养老服务中按规定比例抵扣个人自付部分。

## 窗口

线上：“民政通”；线下协助：乡镇（街道）、村（社区）、养老服务机构；监管主体为县级民政。

## 时限

首次申请审核符合条件的，民政通在5个工作日内发放当月券（临近月底不足5个工作日的可自次月起发）。券当月有效、次月失效。

## 依据文号

桂民发〔2026〕2号

## 注意事项

- 抵扣额度暂定每人每月最高800元；机构长期/短期及日间托养暂按40%，居家上门暂按50%；评估券最高100元。
- 不再符合条件应及时告知，次月停发。
- 本指引不替代平台规则与窗口审核。
