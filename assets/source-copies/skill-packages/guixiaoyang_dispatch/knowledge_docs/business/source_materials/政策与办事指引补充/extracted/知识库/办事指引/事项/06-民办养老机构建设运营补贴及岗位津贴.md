# 事项：民办养老机构建设/运营补贴及从业人员岗位津贴申请

## 适用对象

- 符合条件的民办养老机构（建设补贴、运营补贴）；PPP、公建民营可参照。
- 符合条件的养老机构从业人员（岗位津贴）。

## 办理条件（摘要）

机构需依法登记备案、符合建筑消防食品安全等规范、申请年度内无重大安全责任事故及重大服务纠纷等（详见办法第四条）。运营补贴还需收住规定的四类人员之一。旅居式、会员制或直接售卖床位使用权等情形不予建设/运营补贴。岗位津贴对事业单位在编人员不予发放。

## 所需材料

**建设/运营补贴：**
1. 民办养老机构建设补贴申请表或运营补贴申请表
2. 信用承诺书等办法规定材料
3. 通过广西智慧养老综合服务平台上传

**岗位津贴：**
1. 养老机构从业人员岗位津贴申请表
2. 申请人信用承诺书等
3. 由在职机构向管辖民政部门提出

## 办理步骤

1. 核对是否符合桂民规〔2024〕4号条件。
2. 于当年7月15日前通过智慧养老综合服务平台提出申请（周期：上年7月1日至当年6月30日）。
3. 民政部门属地受理、核查，平台逐级审核审批，并开展抽查或第三方评估。
4. 建设/运营补贴拨付至机构；岗位津贴拨付至护理员个人。

## 窗口

机构备案/管辖的县级（属地）民政部门；线上广西智慧养老综合服务平台。

## 时限

申请截止一般为当年7月15日；资金按预算与审批进度拨付。

## 依据文号

桂民规〔2024〕4号（现行）。桂民规〔2021〕7号为历史版本。

## 注意事项

- 建设补贴为一次性，新增床位平均收住率达30%等条件见办法。
- 骗取冒领将追缴并追责。
- 本指引不替代窗口审核。
