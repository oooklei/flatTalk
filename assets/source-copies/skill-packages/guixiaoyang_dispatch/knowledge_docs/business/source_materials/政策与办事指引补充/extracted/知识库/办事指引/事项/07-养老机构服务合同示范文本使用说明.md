# 事项：养老机构服务合同（示范文本）使用说明

## 适用对象

广西行政区域内养老机构与入住老年人（或其监护人、代理人）签订养老服务合同时参考使用。

## 办理条件

机构依法设立并提供养老服务；双方自愿协商订立服务合同。

## 所需材料

- 《广西壮族自治区养老机构服务合同（示范文本）》
- 双方身份/主体资格证明、老年人相关健康与评估信息等（按合同约定与机构入住流程）

## 办理步骤

1. 查阅桂民函〔2025〕568号通知及示范文本。
2. 机构与老年人（家属）对照示范文本协商服务内容、费用、权利义务等条款。
3. 双方签字盖章后按机构流程办理入住。
4. 合同文本由双方妥善保管。

## 窗口

养老机构入住登记处；政策咨询可向当地民政或市场监管部门了解示范文本推行情况。

## 时限

无统一行政审批时限；以双方签约与机构入住安排为准。

## 依据文号

桂民函〔2025〕568号

## 注意事项

- 示范文本供参考，具体条款可在合法合规前提下协商细化。
- 涉及集中照护补助对象的，鼓励同时签订代扣代缴服务费用协议。
- 本指引不构成法律意见，重大争议应咨询专业人士或主管部门。
