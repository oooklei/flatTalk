# 防城港市AI养老试点5条旅居养老线路产品（大健康产业协会牵头落地版）

防城港旅居养老试点采用「1个大本营 + 5条日游支线 + 6大标准化模块」轻量化旅居模式。

大本营为防城港官方认证旅居机构：嘉路滨海旅居基地（嘉路康旅酒店），长者无需频繁更换住宿。

每条线路半日外出、半日基地康养休整，节奏适配60周岁以上老年群体。

全程深度嵌入药膳、森林、民俗、非遗、长寿在地资源，无购物、无自费项目，配套适老保障与专业康养服务。

## 大本营：嘉路滨海旅居基地（嘉路康旅酒店）

资质保障：列入《2023-2025广西旅居养老机构入选汇总表》官方认证旅居养老机构，符合广西适老化旅居配套规范。

硬件配套：客房防滑地面、安全扶手、感应夜灯、紧急呼叫系统；内设药膳餐厅、康养活动空间、中医理疗室，对接防城港市医疗机构开通应急就医绿色通道。

基础服务：每日晨间养生锻炼、免费健康监测，日间与晚间康养课堂，24小时值守健康管家，专属“阿桂管家”一对一全程随行陪护。

## 线路1 京族滨海文化线

核心定位：非遗滨海康养主题，京族非遗文化+滨海负氧离子疗养，适配热爱民俗、偏好平缓休闲的自理长者。

适配人群：60—75周岁无重大基础病活力长者。

资源嵌入-非遗：京族独弦琴、哈节民俗、传统渔耕文化。

资源嵌入-康养：滨海负氧离子疗养、中医艾灸理疗。

资源嵌入-食药同源：金花茶、海鸭蛋、沙虫、五指毛桃、珍珠黄玉米。

特色餐食：沙虫瘦肉汤、清蒸海鱼、珍珠玉米、五指毛桃养生汤；活动含金滩滨海慢走、浅滩渔耕轻体验。

单日单人零售价：398元；5条组合套餐总价：1880元；优惠：60岁以上长者立减20元/人。

## 线路2 银发爱情边境线

核心定位：边境风情康养主题，适配夫妻结伴、喜爱边境人文的活力长者。

适配人群：60—75周岁自理老年夫妻、结伴旅居长者。

资源嵌入-边境人文：东兴国门、中越友谊大桥、中越界碑、越南民俗手作。

资源嵌入-康养：双人舒缓瑜伽、石斛药膳调养。

资源嵌入-食药同源：石斛、红枣、本地海产杂粮。

特色餐食：屈头蛋养生汤、清蒸海产、杂粮饭、石斛鸡汤、长寿面套餐；活动含京族服饰轻手工体验。

单日单人零售价：368元；5条组合套餐总价：1880元；优惠：夫妻结伴立减30元/对。

## 线路3 壮村民俗康养线

核心定位：壮乡田园康养，壮瑶药膳、田园负氧休闲，适合喜爱乡村、有骨关节/脾胃调理需求长者。

适配人群：60—78周岁自理长者。

资源嵌入-民俗非遗：壮锦、竹竿舞、五色糯米饭非遗技艺。

资源嵌入-康养：田园负氧离子疗养、壮药熏蒸理疗。

资源嵌入-食药同源：艾叶、五指毛桃、本地杂粮果蔬。

特色餐食：五色糯米饭、艾叶鸡汤、豆腐圆、五指毛桃排骨汤；地点在上思壮乡民俗村落，含无公害果蔬轻采摘。

单日单人零售价：388元；5条组合套餐总价：1880元；优惠：60岁以上长者立减20元/人。

## 线路4 森林轻氧休闲线

核心定位：十万大山森林负氧离子疗愈，适配高血压、呼吸道、睡眠亚健康长者。

适配人群：60—78周岁自理长者。

资源嵌入-生态康养：十万大山高负氧森林步道、林间茶疗。

资源嵌入-理疗：中医慢病专项调理。

资源嵌入-食药同源：金银花、玉米须、野生菌、深山野菜。

特色餐食：野生菌菇鸡汤、清炒山野菜、玉米须药膳养生晚餐；活动含森林呼吸操、林间冥想、免费吸氧点位。

单日单人零售价：428元；5条组合套餐总价：1880元；优惠：慢病调理人群赠送理疗1次。

## 线路5 芒街跨境体验线

核心定位：中越跨境人文康养，适配自理能力强、持有有效出入境证件的长者。

适配人群：60—75周岁，持有有效护照签证、无严重基础病活力长者。

资源嵌入-跨境资源：东兴口岸、芒街人文、越南草本康养。

资源嵌入-食药同源：西洋参、当归、海产食材。

特色餐食：越南特色养生午餐（清蒸龙利鱼、清淡河粉）、当归药膳养生晚餐；活动含越南草本古法轻按摩、草药茶品鉴。

单日单人零售价：598元；5条组合套餐总价：1880元；优惠：不含护照、签证办理费用。

## 定价规则与配套标准

定价规则：单条线路可单独报名，5条线路可打包购买组合套餐。

报价包含：大本营当日住宿、全天三餐、全程适老化交通、所有体验项目、人身意外险、康养理疗、管家陪护。

全程无任何强制购物、无隐形自费项目；单人入住需补单间房差，夫妻同行、高龄长者设专属优惠。

住宿：嘉路康旅适老化双人标间。

餐饮：营养师定制低盐低脂药膳餐，可适配糖尿病、痛风等特殊饮食需求。

出行：15座内平稳商务车，随车配备靠枕、毛毯、温水、吸氧、急救物资。

服务：每团专属阿桂管家、持证康养师全程陪同。

保险：每人配置10万元人身意外险+1万元医疗险。

## 六大标准化模块

住宿适老化：统一使用嘉路滨海旅居基地，紧急呼叫、防滑、扶手、感应夜灯全部达标。

药膳餐饮：每条线路匹配本地长寿药食同源食材，营养师分年龄、分病症定制专属菜单。

康养活动：固定晨间锻炼、日间理疗、晚间养生三段式康养安排。

轻量出行：统一半日外出、半日休整模式，严控步行强度，沿途配套休息点位。

在地体验：每条线路植入本地非遗、森林、边境、长寿特色资源，规避高强度体力活动。

安全保障：统一配备急救物资、医疗机构绿色通道、全员投保，24小时管家应急响应。

## 落地实施四阶段

实地踏勘筹备阶段：大健康产业协会牵头，完成五条线路全域点位实地核查，签订标准化服务协议。

服务标准搭建阶段：编制旅居服务标准化SOP手册，组织全岗位培训与上岗考核。

市场运营拓展阶段：面向全区养老机构、老年协会开展线路专场推介，组织体验试运营。

平台对接上线阶段：完成AI养老大脑系统入驻，打通线上运营、可视化监管全流程。
