# 老年人膳食指导原则（WS/T 556—2017）

来源：WS/T 556—2017《老年人膳食指导》第3章。适用于65岁及以上老年人。

老年人膳食应遵循以下六项原则：

## 3.1 食物多样、搭配合理

食物多样、搭配合理，符合平衡膳食要求。

## 3.2 吃动平衡，维持健康体重

能量供给与机体需要相适应，吃动平衡，维持健康体重。

## 3.3 保证优质蛋白质与微量营养素

保证优质蛋白质、矿物质、维生素的供给。

## 3.4 适合咀嚼、吞咽和消化

烹制食物适合老人咀嚼、吞咽和消化。

## 3.5 饮食清淡，注意食品卫生

饮食清淡，注意食品卫生。

## 3.6 必要时合理营养补充

食物摄入无法满足需要时，合理进行营养素补充。
