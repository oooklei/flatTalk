# 老年人能量及宏量营养素参考摄入量（WS/T 556—2017）

来源：WS/T 556—2017《老年人膳食指导》表1。适用于65岁及以上老年人。

说明：
- “轻”“中”指身体活动水平。
- %E 表示占总能量的百分比。
- 蛋白质为推荐摄入量（RNI）。

## 每日能量推荐摄入量（kcal/d）

| 年龄 | 性别 | 轻度活动 | 中度活动 |
|------|------|----------|----------|
| 65岁~79岁 | 男 | 2050 | 2350 |
| 65岁~79岁 | 女 | 1700 | 1950 |
| ≥80岁 | 男 | 1900 | 2200 |
| ≥80岁 | 女 | 1500 | 1750 |

## 蛋白质推荐摄入量（RNI）

| 性别 | 蛋白质 RNI（g/d） |
|------|-------------------|
| 男 | 65 |
| 女 | 55 |

注：65岁~79岁与≥80岁相同。

## 宏量营养素可接受范围（AMDR）

| 营养素 | 每日可接受范围 |
|--------|----------------|
| 总脂肪 | 占总能量 20%~30% |
| 饱和脂肪酸 | 占总能量 <10% |
| n-6 多不饱和脂肪酸 | 占总能量 2.5%~9.0% |
| n-3 多不饱和脂肪酸 | 占总能量 0.5%~2.0% |
| 总碳水化合物 | 占总能量 50%~65% |
| 添加糖 | 占总能量 <10% |

## 智能体问答要点

- 询问某位老年人每日能量时，需结合：**年龄段（65~79 / ≥80）、性别、活动水平（轻/中）**。
- 能量随年龄增长总体下降；同年龄同活动水平下，男性高于女性。
- 蛋白质：男性 65 g/d，女性 55 g/d。
- 脂肪宜控制在总能量 20%~30%，饱和脂肪 <10%，添加糖 <10%。
