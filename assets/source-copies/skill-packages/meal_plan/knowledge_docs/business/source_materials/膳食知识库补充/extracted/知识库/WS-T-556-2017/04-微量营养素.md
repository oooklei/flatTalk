## 当量换算说明

- **视黄醇活性当量（RAE, μg）** = 膳食或补充剂来源全反式视黄醇(μg) + 1/2 补充剂纯品全反式β-胡萝卜素(μg) + 1/12 膳食全反式β-胡萝卜素(μg) + 1/24 其他膳食维生素A原类胡萝卜素(μg)。
- **α-生育酚当量（α-TE, mg）**：膳食中总α-TE当量(mg) = 1×α-生育酚(mg) + 0.5×β-生育酚(mg) + 0.1×γ-生育酚(mg) + 0.2×δ-生育酚(mg) + 0.3×α-三烯生育酚(mg)。
- **叶酸当量（DFE, μg）** = 天然食物来源叶酸(μg) + 1.7×合成叶酸(μg)。
- **烟酸当量（NE, mg）** = 烟酸(mg) + 1/60 色氨酸(mg)。

## 智能体问答要点

- 老年人钙 RNI 为 **1000 mg/d**；维生素D RNI 为 **15 μg/d**；维生素C RNI 为 **100 mg/d**。
- 钠 AI：65~79岁 1400 mg/d，≥80岁 1300 mg/d（与限盐建议呼应）。
- 锌、维生素A、B1、B2、胆碱、烟酸等存在性别差异，回答时需区分男女。
- ≥80岁部分矿物质（磷、钠、镁、氯）及烟酸推荐量略低于65~79岁。
