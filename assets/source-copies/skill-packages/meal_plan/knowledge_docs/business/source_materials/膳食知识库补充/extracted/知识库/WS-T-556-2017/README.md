## 检索建议

- **按人画像检索**：年龄（65~79 / ≥80）+ 性别 + 活动水平 → 先查 `03` 定能量，再查 `07` 定食物量。
- **按主题检索**：原则 → `02`；某类食物 → `06`；具体营养素数值 → `03`/`04`/`05`。
- **回答约束**：本库仅覆盖健康膳食指导；疾病治疗期饮酒禁忌、医用食品使用等须提示“遵医嘱/营养师指导”。
