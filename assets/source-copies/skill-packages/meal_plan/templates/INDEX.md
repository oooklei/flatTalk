# meal_plan templates

## HTML

- `html/plan.html`: approved chat-card meal answer prototype, used by `meal_plan.plan.v1`.
- `html/overview.html`: approved overview variant.
- `html/timeline.html`: approved flow/timeline variant.
- `html/dashboard.html`: approved dashboard/report variant.

## Slots

- `html/slots/summary-card.html`: top summary, audience, total kcal, salt limit.
- `html/slots/meal-section.html`: repeatable meal section for breakfast/lunch/dinner.
- `html/slots/nutrition-note.html`: nutrition ratio and chronic-condition note.
- `html/slots/related-questions.html`: related question/action suggestions.

## Data

- `data/plan.sample.json`: sample data aligned with the approved meal answer prototype.

## Registry

- `registry.json`: template ids, render modes, allowed slots, LLM selection policy, actions, and data schema references.
