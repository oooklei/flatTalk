## 二、common — 公共模板（6个）

| 模板ID | 语义描述 | 典型用户输入 |
|--------|---------|-------------|
| answer | 通用健康咨询答复兜底卡片，用于文本回复展示 | "高血压注意什么"、"散步多久合适"、"吃什么补钙" |
| fallback_error | 异常错误友好提示卡片，用于系统出错时的兜底展示 | （系统自动触发） |
| policy_card | 养老政策咨询主卡片，展示补贴/长护险/高龄津贴等政策解答 | "养老补贴怎么申请"、"长护险是什么"、"高龄津贴多少"、"社区居家养老政策" |
| policy_list_card | 政策列表卡片，用于展示多条政策信息的列表 | "有哪些养老政策"、"政策汇总"、"补贴政策一览" |
| policy_detail_card | 政策详情卡片，用于展示单条政策的详细解读内容 | "长护险详细解读"、"这个政策具体怎么操作" |
| policy_apply_guide_card | 申请指引卡片，用于展示政策申请流程、条件和所需材料 | "长护险怎么申请"、"申请需要什么材料"、"办理流程是什么" |

## 三、find_service — 养老服务发现与匹配（15个）

| 模板ID | 语义描述 | 典型用户输入 |
|--------|---------|-------------|
| service_recommend | 综合服务推荐页，含维度标签+服务卡列表+拓展推荐+猜你喜欢 | "帮我找个护工"、"推荐上门护理"、"需要助浴服务"、"陪诊服务" |
| service_card | 单个服务推荐项，含图标/评分/价格/服务商可信指标 | "推荐一项服务"、"有没有助餐"、"这一个服务怎么样" |
| service_detail | 服务详情页，含介绍/标签/特色/时间/咨询热线 | "这项服务介绍"、"有什么特色"、"服务时间"、"咨询热线" |
| service_catalog | 养老服务目录全览，按分类展示全部可用服务 | "有哪些服务"、"服务目录"、"全部服务"、"服务分类" |
| service_expand | 按维度拓展推荐，展示空闲率/环境/响应速度最优的服务选择 | "其他优质选择"、"空闲率最高的"、"环境得分高的"、"响应最快的" |
| service_guess_like | 个性化精选横向卡，含封面图/标签/价格/服务商信息 | "猜我喜欢"、"为您精选"、"有没有推荐的旅居路线" |
| service_intent | AI意图识别可视化，展示置信度/抽取实体/紧急级别 | "AI理解了吗"、"你识别到了什么"、"我的需求是什么" |
| service_thinking | AI处理中加载态，展示意图识别→实体抽取→知识库匹配动画 | "正在分析"、"AI思考中"、"还在处理吗" |
| service_order_form | 服务预定表单，含服务/预约人/电话/地址/日期/时段字段 | "我要预定"、"帮我下单"、"预约服务"、"填写信息" |
| service_order_ticket | 下单成功凭证，展示订单号/服务/预约信息/状态 | "下单成功了吗"、"订单号多少"、"预定完成" |
| order_preview | 订单预览确认页，提交前的信息汇总 | "确认订单"、"看一下订单信息"、"提交前检查" |
| order_status | 订单状态进度跟踪，展示服务订单全流程状态 | "我的订单"、"订单到哪了"、"订单进度"、"服务什么时候来" |
| org_profile | 养老机构详情页，展示机构信息/设施/评级/联系方式 | "这个养老院怎么样"、"护理站详情"、"服务中心在哪"、"入住机构" |
| worker_profile | 护理人员详情档案，展示资质/经验/评分/专长 | "护工资质怎么样"、"护理人员介绍"、"上门人员是谁" |
| service_emergency | SOS应急卡，提供一键拨打120/通知家属/标记安全按钮 | "救命"、"SOS"、"打120"、"紧急情况"、"快不行了" |

## 九、模板选择优先级矩阵（高冲突场景）

| 用户输入 | 候选模板A | 候选模板B | 最可能选中 | 原因 |
|---------|----------|----------|-----------|------|
| "附近有什么吃的" | nearby_food_card | nearby_map_overview | nearby_food_card | 精确命中"吃"关键词 |
| "帮我推荐膳食" | diet_card | service_recommend | diet_card | "膳食"命中 meal_plan 场景 |
| "一周计划" | weekly_plan | travel_itinerary_card | weekly_plan | "一周/七天"精确命中 |
| "附近医院" | nearby_wellness | nearby_map_category | nearby_wellness | "医院"属于康养类 |
| "怎么去三亚" | travel_transport_card | nearby_map_route | travel_transport_card | "怎么去"命中交通类 |
| "附近有什么" | nearby_map_overview | nearby_list | nearby_map_overview | "附近"是总览触发词 |
| "有什么服务" | service_catalog | service_recommend | service_catalog | "目录/全部"倾向列表 |

## 十、附录

### 10.1 数据源说明

| 技能包 | 数据来源 |
|--------|---------|
| nearby_resource | 静态389条JSON + 腾讯地图POI搜索 + Tavily富化 |
| travel_route | 腾讯天气API + 金跳动产品API + 腾讯地图地理编码 |
| health_risk_warning | 云诊365(yz365)远程体检指标 + 规则引擎 |
| meal_plan | 慢病膳食知识库 + Tavily营养搜索 |
| find_service | 养老服务数据库 + 评分/空闲率算法 |
| dispatch_manage | 工单系统API |
| common | 无外部数据源 |

### 10.2 特殊模板说明

| 模板 | 特殊说明 |
|------|---------|
| health_risk_rule_card | HTML片段文件（无完整HTML结构），通过data-template标识 |
| health_risk_signal_card | 同上 |
| health_warning_card | 同上 |
| service_emergency | SOS紧急短路触发，跳过场景评分直接渲染 |
| nearby_summary | 纯文本无地图，弱网/无障碍场景专用 |
| service_thinking | 加载态卡片，无用户输入触发，系统自动展示 |
