# flatTalk 模板库

本文档整理了 flatTalk 系统中所有卡片模板的语义化描述，帮助理解每个模板的作用、适用场景和必备条件。

---

## 一、健康风险预警类

### 1. 风险评估卡片 (risk_assessment_card)

**有什么作用？**
帮助长者和家属了解老人未来可能面临的健康风险，让预防走在疾病前面。

**能做什么？**
- 根据体检数据和体质信息，评估易患疾病风险
- 按风险程度分级展示：重度、中度、轻度
- 每项风险都有明确的分数和预警标识

**有什么意义？**
让"治未病"成为可能，长者可以根据风险提示提前调整生活方式，家属也能有针对性地关注老人健康变化。

**要素和资源？**
- 风险项目名称（如乳腺结节风险评估、骨质疏松症风险评估）
- 风险分数（数值）
- 风险等级（预警/中度风险/轻度风险）

**适用场景？**
- 老人完成年度体检后，需要了解潜在健康风险
- 家属想提前知道老人可能出现的健康问题
- 居家照护人员需要制定预防性护理计划

**必备条件？**
- 需要有老人的体检数据或健康档案
- 至少包含一项可评估的健康指标

---

### 2. 风险预警卡片 (risk_warning_card)

**有什么作用？**
以简洁的警示形式提醒长者和家属当前存在的健康隐患，需要引起重视。

**能做什么？**
- 以醒目的三角形警示图标标注每项风险
- 用通俗语言解释风险可能带来的身体表现
- 支持多条预警并列展示

**有什么意义？**
让健康隐患不被忽视，帮助长者在风险演变成疾病前采取行动。

**要素和资源？**
- 警示图标（红色三角形）
- 风险描述（如"提示肝胆异常，可能有睡眠不佳、情志不畅等表现"）

**适用场景？**
- 健康体检报告中存在异常指标
- 日常监测发现潜在风险
- 需要向家属传达老人健康警示

**必备条件？**
- 存在可识别的健康风险信号
- 风险已通过专业渠道确认

---

### 3. 健康报告卡片 (health_report_card)

**有什么作用？**
为老人生成一份完整的健康评估报告，汇总风险、预警和调养建议。

**能做什么？**
- 整合风险评估、风险预警、膳食调养三大模块
- 以报告形式呈现，适合打印或分享给家属
- 每个模块都有清晰的标题和分隔

**有什么意义？**
让老人和家属获得一份"看得懂、用得上"的健康报告，不再是晦涩的医学术语，而是具体的行动指南。

**要素和资源？**
- 报告标题：健康风险预警报告
- 风险评估模块
- 风险预警模块
- 膳食调养模块
- 免责声明

**适用场景？**
- 年度健康体检后生成综合报告
- 居家照护评估报告
- 养老机构健康档案更新

**必备条件？**
- 至少有风险评估或膳食调养一项内容
- 建议配合专业医疗机构数据

### 4. 膳食调养卡片 (dietary_regimen_card)

**有什么作用？**
告诉老人"吃什么、怎么吃"，根据体质和健康状况提供个性化的饮食指导。

**能做什么？**
- 明确列出宜食和忌食的食物类别
- 推荐具体的食疗方，包含药材、食材、烹饪方法和功效
- 每道食疗方配有示意图，方便识别

**有什么意义？**
让"药食同源"的理念走进日常餐桌，帮助长者在吃饭中调理身体，预防疾病。

**要素和资源？**
- 宜食食物清单（如小米、山药、莲子、百合）
- 忌食食物清单（如辣椒、烧烤、冰淇淋）
- 食疗方推荐（如三花橘皮茶）
- 药材、食材、烹饪方法、功效说明

**适用场景？**
- 老人有慢性病需要饮食调理
- 季节性养生建议
- 体质辨识后的膳食指导

**必备条件？**
- 需要知道老人的体质或健康状况
- 或有明确的调养目标（如疏肝理气、健脾和胃）

## 二、旅居出行类

### 5. 旅居路线卡片 (route_card)

**有什么作用？**
为老人推荐合适的康养旅居路线，让出行不再是负担，而是健康生活的一部分。

**能做什么？**
- 展示路线目的地、天数、价格
- 列出路线亮点（如海滨慢行、家属陪同、交通便利）
- 显示预订状态和产品来源
- 提供后续操作入口（对比目的地、检查可订、测算预算）

**有什么意义？**
帮助长者和家属快速了解旅居产品，做出"去哪里、住多久、花多少"的决策，让养老旅居变得简单可行。

**要素和资源？**
- 路线名称、目的地、天数
- 价格标签、预订状态
- 路线亮点标签
- 后续操作按钮

**适用场景？**
- 老人想外出旅居养老
- 家属帮老人挑选康养路线
- 了解不同目的地的旅居选择

**必备条件？**
- 有可推荐的旅居产品数据
- 至少有目的地和天数信息

### 6. 旅居行程安排卡片 (travel_itinerary_card)

**有什么作用？**
把"每天干什么"说得清清楚楚，让老人出行心里有数，家属也能放心。

**能做什么？**
- 按天展示行程安排，每天有主题和时段划分
- 上午、下午、傍晚三个时段分别安排活动
- 每天贴心提示注意事项（如"防滑鞋"、"单日车程不超过40分钟"）
- 支持天数据切换，查看不同日期行程

**有什么意义？**
让旅居不再是"走马观花"，而是有节奏、有休息、有照护的深度体验。老人可以根据自己体力灵活选择，家属也能看到每天的安排是否合理。

**要素和资源？**
- 每日主题（如"抵达安顿"、"白浪滩"、"赶海体验"）
- 时段安排（上午、下午、傍晚）
- 具体活动内容
- 贴心提示

**适用场景？**
- 确定旅居产品后查看详细行程
- 家属了解老人每天的活动安排
- 出行前的行程确认和调整

**必备条件？**
- 已有推荐的旅居路线
- 行程数据包含每日安排

### 7. 旅居天气风险卡片 (travel_weather_risk_card)

**有什么作用？**
出发前了解目的地天气，帮助长者和家属判断是否适合出行，需要做什么准备。

**能做什么？**
- 显示目的地当前天气（温度、天气状况、风力）
- 展示未来几天的天气预报
- 根据天气情况给出长者风险提示（如高温防中暑、降雨防滑倒）
- 无法获取天气时提供通用提醒

**有什么意义？**
让"看天出行"成为可能，帮助长者避开恶劣天气，选择最佳出行时机。对于慢病老人，天气变化可能影响身体状况，提前知晓有助于做好准备。

**要素和资源？**
- 目的地城市名
- 当前天气数据（温度、天气、风力、湿度）
- 未来几日天气预报表格
- 长者风险提示

**适用场景？**
- 出行前查看目的地天气
- 评估是否需要调整行程
- 提醒老人携带合适的衣物和药品

**必备条件？**
- 明确的目的地城市
- 天气接口可正常调用

## 三、膳食营养类

### 8. 膳食卡片 (diet_card)

**有什么作用？**
告诉老人"今天吃什么"，每顿饭都有安排，营养均衡、适合长者体质。

**能做什么？**
- 按早、午、晚三餐展示每日膳食
- 每道菜显示热量和分量
- 标注适用人群（如70岁以上、低盐低脂低糖）
- 提供营养配比参考

**有什么意义？**
让老人的餐桌不再是"凑合"，而是有计划、有营养、有讲究。慢病老人可以根据禁忌标签（如糖尿病、高血压）选择适合的食物。

**要素和资源？**
- 日期标签
- 适用人群说明
- 每餐菜品列表（名称、热量、分量）
- 营养配比参考
- 禁忌提示标签

**适用场景？**
- 居家养老每日膳食规划
- 养老机构制定长者食谱
- 慢病老人饮食指导

**必备条件？**
- 有膳食搭配建议数据
- 或有营养师推荐的食谱方案

## 四、政策咨询类

### 9. 养老政策卡片 (policy_card)

**有什么作用？**
帮老人和家属了解"有什么补贴、怎么申请"，让养老政策不再难懂。

**能做什么？**
- 解答养老政策相关问题
- 列出补贴类、服务类、办理类政策条目
- 根据用户问题补充具体政策和申请条件

**有什么意义？**
让养老政策"看得懂、用得上"，帮助长者享受到应有的福利和补贴，不因信息不对称而错过权益。

**要素和资源？**
- 政策分类标签（补贴类、服务类、办理类）
- 政策条目内容
- 申请条件和办理流程提示

**适用场景？**
- 老人询问养老补贴政策
- 家属了解长期护理保险
- 咨询养老服务申请流程

**必备条件？**
- 有政策知识库或政策数据来源
- 用户提出明确的政策问题

**有什么作用？**
当系统出现异常时，以友好方式告知用户，避免冷冰冰的错误信息。

**能做什么？**
- 说明发生了什么问题
- 提供可能的解决方案或重试入口

**有什么意义？**
让系统故障也能成为良好的用户体验，而不是让用户困惑和无助。

## 模板使用指南

### 如何选择模板？

1. **根据用户意图**：用户问"天气"，选天气卡片；用户问"吃什么"，选膳食卡片
2. **根据数据可用性**：有天气数据才能用天气卡片，有产品数据才能用路线卡片
3. **根据场景优先级**：同一意图可能对应多个模板，选择信息最完整的那个

### 模板之间的关系

- **路线卡片 → 行程卡片 → 天气卡片**：用户先看路线，再了解行程，最后确认天气
- **风险评估 → 风险预警 → 膳食调养**：三者在健康报告中可以组合使用
- **服务推荐 → 派单状态 → 服务完成**：服务流程的三阶段卡片
