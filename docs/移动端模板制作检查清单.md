# 移动端模板制作检查清单

> 基于 2026-08-07 手机空白卡片修复实践总结。每次新建或修改模板时逐项核对。

---

## 一、JavaScript 检查

- [ ] 模板中**无任何 `<script>` 标签**（包括 `<script type="application/json">` 示例数据块）
- [ ] 无 `onclick` / `onload` / `onerror` 等内联事件属性
- [ ] 无 `javascript:` 伪协议链接
- [ ] 无客户端动态 DOM 生成（`document.createElement`、`innerHTML =`）

> 验证命令：`grep -c '<script' template.html` → 应为 **0**

---

## 二、地图检查

- [ ] 无 `new TMap.Map(` 调用
- [ ] 无 `map.qq.com/api/gljs` 外链引用
- [ ] 无 `data-map-mode`、`data-layout="map"`、`id="mapCanvas"` 属性
- [ ] 交互式地图已替换为**静态地图图片**：
  ```html
  {{#has_static_map}}
  <img src="{{static_map_img}}" loading="lazy" style="width:100%;border-radius:10px;">
  {{/has_static_map}}
  ```
- [ ] 走线图 / 路线图由**服务端生成 SVG** 并注入容器，非客户端绘制
- [ ] 导航功能用**外部链接**，非嵌入式地图 SDK：
  ```html
  <a href="{{nav_url}}" target="_blank" rel="noopener">🧭 导航</a>
  ```

---

## 三、数据渲染检查

- [ ] POI 列表使用 **Mustache `{{#poi_items}}` 服务端渲染**，非客户端 JS 循环
- [ ] 空数据有 `{{^poi_items}}` 兜底提示
- [ ] `model-service.js` 中已提供对应 Mustache 字段（`poi_items`、`has_poi_items`、`static_map_img`、`route_steps` 等）
- [ ] 路线步骤用 `{{#route_steps}}` 数组渲染

---

## 四、图片展示检查

- [ ] 景点 / 配套图片用 `<img loading="lazy">` **罗列展示**
- [ ] 无弹窗 / 浮层 / 轮播 JS 组件
- [ ] 图片 URL 经 Mustache 渲染，非客户端拼接
  ```html
  {{#spot_cards}}
  <div class="spot-card">
    {{#has_image}}<img src="{{first_image}}" alt="{{name}}" loading="lazy">{{/has_image}}
    <h3>{{name}}</h3>
    <p>{{desc}}</p>
  </div>
  {{/spot_cards}}
  ```

---

## 五、CSS 检查

- [ ] 使用共享类名（`.nb-*`）的模板**保留** `<link rel="stylesheet" href="_base.css">`
- [ ] 同时保留 `<link rel="stylesheet" href="_design_tokens.css">`
- [ ] `<link>` 的 `href` 用**相对路径**（`_base.css`，不是 `/_base.css`）
- [ ] 自包含模板（无外部 CSS 依赖）确认所有样式都在内联 `<style>` 中
- [ ] 内联 `<style>` 中包含 `:root` / `body` 基础样式（底色、字号）

---

## 六、布局检查

- [ ] 添加 `data-layout="vertical"` 适配手机竖向滚动
- [ ] 卡片宽度自适应（`max-width` + `width:100%`），不出现横向溢出
- [ ] 文字 `overflow-wrap: anywhere` 或 `word-break` 防长文本撑破布局
- [ ] 图片 `max-width: 100%` 防超出屏幕

---

## 七、iframe 隔离规避

确认模板**不包含**以下会触发 iframe 隔离的特征：

- [ ] 无 `data-map-mode` 属性
- [ ] 无 `data-layout="map"`
- [ ] 无 `id="mapCanvas"`
- [ ] 无 `class` 含 `nb-map`
- [ ] 无 `<script src="...map...">` 外链
- [ ] 无 `map.qq.com/api/gljs`
- [ ] 无 `new TMap.Map(`

---

## 八、部署检查

- [ ] `docker cp` 后执行 `docker exec -u root flattalk-app chown -R 1001:1001 /app/src/` 修复属主
- [ ] 容器重启后状态为 `Up (healthy)`
- [ ] 验证远程文件 `grep -c '<script'` 为 0
- [ ] mobile.html 版本号已更新（如 `v=20260807-xxx`）防止缓存

---

## 快速验证脚本

```bash
# 在模板目录下执行，检查所有 html 文件
for f in *.html; do
  scripts=$(grep -c '<script' "$f" || true)
  events=$(grep -c 'on[a-z]*=' "$f" || true)
  tmap=$(grep -c 'TMap\|map\.qq\.com' "$f" || true)
  echo "$f → script:$scripts events:$events tmap:$tmap"
done
# 所有数值应为 0
```
