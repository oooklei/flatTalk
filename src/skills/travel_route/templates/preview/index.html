travel_route 模板预览

route_card

layout: vertical

required: routeTitle, destination, days, highlights

展示老人旅居路线规划、目的地、季节、预算、健康安全、交通接驳和预订动作的竖向卡片

travel_base_card

layout: vertical

required: title, bases

旅居康养基地推荐卡：为何选康养基地说明+多基地卡片（首选徽标、副标题、地址、推荐理由、三餐/设施/医疗/配套明细、价格预估、订房与详情按钮），用于康养基地推荐场景

travel_itinerary_card

layout: vertical

required: title, days

旅居行程安排卡：按天分段的行程时间线（顶部天数胶囊点击切换+主题+上午/下午/晚间/餐饮时段+底部说明），用于多日旅居行程规划展示

travel_medical_card

layout: vertical

required: title, groups

医养配套方案卡：就近医疗/便民购药/出行协助等图标列表+温馨提示与免责说明，用于旅居康养医养配套展示

travel_need_summary_card

layout: vertical

required: title, desc, tags

旅居康养需求总结卡：展示AI解析的出行需求标签（出行/人群/医养/食宿/行程）与方案匹配结论，用于个性化旅游推荐、康养基地推荐对话的第一步需求确认

travel_plan_summary_card

layout: vertical

required: title, rows, totalPrice

旅居方案总结卡：目的地/天数/人数/住宿/预估费用汇总+立即预定按钮+您可能还想了解追问列表，用于旅居方案最终确认场景

travel_spot_card

layout: vertical

required: title, spots

适老化景点推荐卡：景点列表（名称+免费/收费与行程标签+康养价值+长者玩法+交通时长），用于旅居适老化景点推荐场景

travel_transport_card

layout: vertical

required: title, tickets

交通指南卡：高铁购票（车次时刻+二等/一等座余票价+跳转12306）+当地包车建议列表，用于旅居往返交通与当地出行方案展示

travel_weather_risk_card

layout: vertical

required: city

旅居路线目的地天气风险研判（腾讯天气实时数据）
